Build Docker image:
    docker build -t redis-custom-docker .

Run Docker container:
    docker run -d -p 6379:6379 redis-custom-docker

Check if the container is running:
    docker ps
    docker exec -it <container_id> redis-cli
    docker exec -it 08289cc5f2fe redis-cli
    PING # Nên trả về PONG
